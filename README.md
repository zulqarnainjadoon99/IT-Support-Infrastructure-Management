## Project Overview

This project demonstrates the practical application of IT support and infrastructure management concepts through a simulated corporate office environment.

The work covers computer hardware, operating systems, software management, networking, system administration, cybersecurity, help desk operations, troubleshooting and technical documentation.

- Defined the purpose, scope and objectives of the IT support project.
- Established the simulated project environment and responsibilities.

### 02. Organization Profile & IT Environment

### 17. Lessons Learned & Final Project Closure
